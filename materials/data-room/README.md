# Data Room

Store fundraising documents here. Typical data room contents:

## Checklist

- [ ] **Pitch deck** (latest version)
- [ ] **Financial model** — projections, assumptions, unit economics
- [ ] **Cap table** — current ownership breakdown
- [ ] **Corporate documents** — articles of incorporation, operating agreement
- [ ] **Team bios** — founders and key team members
- [ ] **Product demo** — video walkthrough or live demo link
- [ ] **Customer references** — testimonials, case studies, logos
- [ ] **Market research** — TAM/SAM/SOM analysis, competitive landscape
- [ ] **Legal** — any existing investor agreements, IP assignments
- [ ] **Metrics dashboard** — key KPIs, growth charts

## Organization

Place documents in this directory. Use clear naming:
- `financial-model-2026-Q1.xlsx`
- `cap-table-2026-04.xlsx`
- `vester-pitch-deck-v3.pdf`
